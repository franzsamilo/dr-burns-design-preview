# drburns knowledge base

Knowledge-base package for Jeffrey S. Burns DDS / DreamSmile.

Included:
- Client markdown documents and research notes
- Figma template reference links and captured section maps
- Current website snapshot, extracted WordPress/current-site template files, and manifest
- Website build files and assets
- Media analysis/catalog documents and generated thumbnails
- Raw tables and project documentation
- WordPress partials from the homepage redesign experiment

Not included:
- `Media/` raw video/photo source folder (~21GB)
- `Current Website/Archive/JeffreyBurns.zip` (~490MB), because GitHub rejects normal Git files over 100MB and Git LFS is not available in this environment. The extracted WordPress/current-site files from that archive are included under `Current Website/Extracted/`.
